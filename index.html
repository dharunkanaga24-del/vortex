Connecting Your Arduino & Firebase

1. Where to Paste Your Firebase Config

Open the file src/config.js in your code editor and replace the placeholder object with your Firebase Web App credentials:

export const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "your-project.firebaseapp.com",
  databaseURL: "https://your-project-default-rtdb.firebaseio.com",
  projectId: "your-project-id",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};

2. Database Type & Paths

In src/config.js, configure whether you are using Realtime Database ("rtdb") or Firestore ("firestore"), and customize your JSON paths:

export const DATABASE_TYPE = "rtdb"; // or "firestore"

export const FIREBASE_PATHS = {
  current: "airQuality/current",
  history: "airQuality/history"
};

3. Arduino / ESP32 Data Payload Format

Your microcontroller should publish JSON telemetry matching this structure:

{
  "pm25": 28.4,
  "pm10": 42.1,
  "co2": 680,
  "temperature": 26.5,
  "humidity": 58.0,
  "aqi": 68,
  "timestamp": 1727000000000,
  "deviceId": "AirSense-01"
}

4. Arduino Sketch & Security Rules

Ready-to-flash Arduino/ESP32 code is located in arduino/AirSense_ESP32_Firebase.ino, and sample production security rules are in database.rules.json.
